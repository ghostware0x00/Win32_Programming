## `user32.dll`


- **Role :**
    - its windows's win32 user interface engine.
    - foundational core libraries of win32 subsystem.
    - implements the standard graphical user interface(GUI) of windows like the windows, user inputs, standard buttons, cursor, handle mouse clicks ...etc...

## `ntds.dll`

- ntdll.dll acts as the fundamental bridge between the user-mode Win32 subsystem (such as `kernel32.dll` and `user32.dll`) and the core Windows kernel (`ntoskrnl.exe`).
